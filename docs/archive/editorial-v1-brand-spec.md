## Vantara 的映射边界

[Vantara](https://vantara.in/en) 是**宏观布局参照**，不是代码、品牌、字体或摄影素材供应方。

| 参考结构 | aJay 转译 |
|---|---|
| 沉浸式首屏与胶囊导航 | 金融区夜景、公司身份、摘要/模型/证据入口 |
| 大字阶与留白 | 研究章节标题、数据说明和长文本阅读节奏 |
| 全宽摄影转场 | 上海夜景的长期研究分隔 |

不搬运 Vantara 的 HTML/CSS/JS、logo、照片、文案或 GT Ultra 字体文件。布局与样式为项目内实现，保留原有 Python 数据组装链路。

- 标题：`Iowan Old Style`、`Palatino Linotype`、`Songti SC`、Georgia、serif。

- 不请求字体 CDN；系统字体因设备而异，排版须以实际浏览器检查为准。
- 主标题 `clamp(50px, 6.3vw, 96px)`；章节标题 `clamp(32px, 4vw, 56px)`，移动端另有覆盖。

- 不播放分数递增动画；低动效偏好关闭装饰动画与过渡。

## 图像与人物说明

当前采用 `manhattan-night.png`、`shanghai-night.png`，以及黑白方法论肖像 `buffett-portrait.png`、`simons-portrait.png`。

这些是 **AI 生成的摄影质感图像 / 肖像**，不是实拍、历史档案、真人参与证明或投资意见。人物附近与 alt 中保留 AI 生成及“非本人观点或背书”。肖像权威感、角色人数都不是置信度证据。

内置图像工具未返回可核实的模型版本字段，不标注“Image 2.5 已生成”。完整 prompt、路径与哈希见 `IMAGE-PROVENANCE.md`、`BUFFETT-PORTRAIT-PROVENANCE.md`、`SIMONS-PORTRAIT-PROVENANCE.md`。先前自然晨光与庭院图仅为未采用概念稿。

## 数字与置信度语言

- 综合分是 `overall_score` 启发式研究分；有效性门控通过后才显示有限数值。缺失显示 `—`，不补造 0/50/100；有效的真实 0 可以显示。
- 维度分遵守 `score_status`；缺失、不适用、过期、未知旧缓存及定性启发式不冒充量化测量。
- 角色分来自 `score`；旧 `confidence` 不替代分数或概率。`rule_coverage_pct` 只称规则可执行比例，披露可能包含默认特征。
- `panel_consensus` 只称模拟一致度；角色共享输入，不是独立专家样本。
- 行情图只画有效输入序列。合成预览有显著 DEMO 标记；缺失序列保留空状态，不造走势。
- 指纹匹配只表示当前输入与 AI 审阅记录匹配，不表示人工签核或分析正确。
