# 连续研究汇报网站：用户层设计方向

2026-09-09。已逐张查看四张 `*-photography.png` 与用户截图；仅设计建议，未修改源码。

## 方向纠正

上一版解决的是一个视口的可读性，未解决用户要求的完整网站。静态局部通过不等于产品方向通过。现在明确撤销“城市切换 + 单屏观点切换”为主结构的建议。

**主产品是有章节、有工具、有推演深度的连续研究报告；摄影是空间叙事，人物是具体研究工作的汇报者。** 用户向下滚动应获得新的分析能力与证据，而不是下一张照片。保留正常滚动，不以全屏轮播/滚轮劫持替代网页。

## 1. 连续信息架构

固定极薄导航只保留：结论 / 生意 / 估值 / 分歧 / 行动条件 / 来源，以及导出入口。城市名退到摄影署名，不再作为控件。

| 连续章节 | 用户此刻要完成的任务 | 主要功能与信息 | 空间与汇报者 |
|---|---|---|---|
| 01 开场简报 | 20 秒知道是什么、值不值得继续读 | 标的/快照时间、核心判断、最强支持与反对、数据缺口摘要；页内跳转而非“进入网站”按钮 | 纽约近景：进入研究；Buffett 以紧凑半身+一条有依据的判断开场 |
| 02 生意与质量 | 判断回报能否持续、增长来自哪里 | 财务时间序列、现金流核验、护城河、治理、同行/产业链/景气；展开原始数据 | 上海宏伟纵向图贯穿此整段至少约 2–3 个视口；Buffett → Lynch → Munger 分别汇报质量、增长、脆弱性 |
| 03 价格与模型 | 在假设变化下理解价值区间 | DCF/可比估值/敏感性、基准与压力假设、来源、可恢复默认输入；缺模型则诚实未评估 | 伦敦立面作为横向结构细节/侧边取景；Graham 汇报资产与安全边际，Simons 审核方法边界 |
| 04 市场与分歧 | 区分公司判断与市场路径，检验不同解释 | 行情趋势、资金/事件、宏观、同题分歧、观点筛选与全部适用流派；不是投票决定涨跌 | 香港横幅打开视野；Soros / Dalio / Livermore 分别汇报反馈、环境与时机 |
| 05 决策条件 | 知道什么新事实会改变判断 | 风险清单、条件价格、催化剂、需补证据、持仓观察；缺失值不生成机械交易指令 | 回到克制纯色研究桌，不新增第五张装饰图；不同汇报者以旁注形式提出改变观点的条件 |
| 06 研究底册 | 核验、复用、导出 | 完整来源、采集时间、原始数据、方法/评分说明、所有角色记录、下载/打印/分享 | 文档工作面；摄影版权说明放此处，依然可从图片旁直接到达 |

**原报告功能的恢复不是末尾塞一个旧报告 iframe。** 全维透视分布到生意/市场/风险；机构模型在估值主文；分歧/评委/研究笔记合并为可查可比较的视角功能；风险/区间/持仓进入决策条件；来源与导出全程可达。内容可按重要性折叠，但关键结论、主要图表与模型结果必须在连续主文可见，不能全部藏进抽屉。

## 2. 四张照片各自的构图方案

### 上海：一栋建筑跨越几屏，不是一张小塔插画

**实际观察**：约 0.44 宽高比；塔尖、旋转楼身、近地建筑有明确连续纵向关系，左右是蓝调天空。它最有价值的是从尖顶到基座的长比例。

**方案**：在“生意与质量”长章节中用一张不重复、不分段重置的连续图。桌面照片宽约 620–780px，按原比例自然高度约 1400–1800px；章节文本分三个真实分析段落伴随其高度展开。图位于页面右侧约 50–60%，塔主体清晰；正文位于左侧稳定底色上，局部天空允许过渡，但不将塔藏在文字后面。正常向下滚动依次呈现塔尖/楼身/基座，让建筑比例自己制造宏伟感。

- 首个视口只见塔上段，不需要同时见塔尖和底部；这是正确结果。
- 章节总长度必须由真实财务/增长/风险内容支撑，禁止为了图片设置两屏空白。
- 不用 `object-fit:contain` 把整塔压进一屏；不横向拉伸；不让每个子段重新出现塔尖。
- 首选文档流内真实长图，而非全屏 sticky 背景。若有轻微视差，也不得改变阅读速度或造成文字滑动。
- 手机保留建筑长图比例：约 350px 宽时约 790px 高。将图与一段两屏左右的生意分析交织，文字置暗色实底/边侧，允许用户滚动看到不同楼层；不要退回 180px 高城市横幅。

### 纽约：街道压缩、前景遮挡，适合开场“抵达”

**实际观察**：近方形构图；Wall St 路牌在中右，左侧虚焦柱形成前景深度，建筑斜线与右上横杆强化街道尺度。它不是天际线。

**方案**：开场右侧约 45% 的近景取景窗，保持路牌完整。左侧简报是明确的排版工作面而非把整张图蒙黑。下缘可与下一章标题短暂衔接，但最多约 0.7–1 个视口，不延展成上海式竖向长景。左侧柱可作为画面边缘而非正文衬底；避免中心裁剪把路牌切掉。人物不要再占同等大的第二张矩形，开场让半身肖像进入文字区边缘。

### 伦敦：重复网格是分析节奏，不适合主视觉巨幅背景

**实际观察**：立面密集窗格覆盖全图，没有干净留白、没有独立地标焦点；底部斜撑与树是有变化的部分。

**方案**：估值章采用明亮/石墨色研究工作面，将照片裁为右侧约 20–28% 宽的立面切片，或章节上方约 240–320px 高的横向细节带。照片网格与下方敏感性表的严格排版呼应，但不把数字直接叠在窗格上。保留底部斜撑作为识别变化，避免只有无穷小窗格。此章视觉主角必须是模型与假设，不是建筑；不用同样的长图滚动秀。

### 香港：横向港湾展开，用作分歧章的宽幅呼吸

**实际观察**：约 1.43 宽高比；上半大面积深蓝天空，右侧高楼、下半密集灯光、左下渡轮/码头构成明确重心。亮度变化大。

**方案**：宽幅约 55–70vh 的章首场景，保留水线与渡轮，不把大楼裁成无城市关系的一根柱子。章节标题/宏观问题位于左上天空，右侧高楼无遮挡；行情图、分歧比较在下方独立稳定底色上展开。只有短暂的“远眺”场景，不做长距离视差，不在闪亮建筑上叠小字。手机可保留整幅横图作为章间过渡，紧接市场功能正文；无需强行竖裁。

## 3. 八位人物：以任务出现，而不是人像图库

- 每位首次出现必须有：姓名、方法范围、当前论点、1 个证据定位、1 个改变判断的条件。模拟标识就近可读；避免伪造本人引言。
- 人物出现顺序由当前任务决定，不按名气或头像排列。一个人可在多个章节用小签名式旁注再次出现，但大肖像最多一次。
- 主文的 8 位分布在整条报告中：Buffett 质量、Lynch 增长、Munger 反向检验、Graham 价格/资产、Simons 方法验证、Soros 市场反馈、Dalio 环境、Livermore 时机。上述是界面角色分工，不是声称其真实当前意见。
- 肖像尺度变化：开场一位中型半身；上海段一位边缘大裁切、两位小型批注；估值段以姓名/窄头像让位图表；分歧段两位中等肖像相对但不 VS 擂台。不要每章复制“左文右人”。
- 观点与图表直接相连：点击人物观点高亮相关数据/证据行，点击反证跳到对应缺口；不能仅换照片。
- “全部视角”是分歧章里的检索/流派筛选/同题对比功能，不是全站底部常驻 8 头像。66 位记录可在此保留，适用/未评估/缺席分开，不用 0 分代替。

## 4. 动效与功能层级

只用三类动效：章节定位/当前进度、图表筛选与参数变化反馈、打开底稿的空间层级。摄影本身随正常滚动进入离开已足够；不需要每到一城都演示转场。禁止城市tab、全屏背景轮播、相同 sticky 场景换4次、磁吸滚动、自动翻人物。

抽屉仅负责行级证据/来源/方法解释，主文负责阅读研究。图表必须有单位、时期、缺失状态；敏感性表保留文字/表格可访问形式。导出连续正文时，展开所有核心分析，不丢掉只存在JS状态的结果。

## 5. 必须达到的验收

1. 向下滚动连续 4 屏，每屏均新增研究问题、图表或功能，而不是图片变化；没有“读完首屏只能点下一人物”的终点。
2. 导航无城市tab；每一项对应研究任务与稳定锚点。用户可直接定位估值、风险与来源。
3. 上海同一塔从上段到基座跨至少两次滚动连续出现，宏伟比例保留；纽约/伦敦/香港的展示模式明显不同。
4. 四张图不需要同时全高全宽出现；关闭图片后报告仍有完整信息架构，打开图片后具有真实空间层次。
5. 原报告的重要功能在相应章节可见、可用，不能靠“旧完整版”链接声称恢复。
6. 八位人物各自承担研究工作；任意抽一位都能找到具体证据关联，而不是仅有姓名/口号。
7. 390px 手机有正常文档流、无横向溢出；上海仍有长纵构图，其它照片不会跟着变成长塔方案。

**最终建议：先完成连续 IA 与原功能映射，再以四张图逐章设计；不要先做四个漂亮场景，再找数据填缝。**
