本轮在既有连续报告上迭代，实现与验收阶段仅在本地进行。验收后，用户已明确授权推送；源码、分发素材、测试与文档纳入提交，行情缓存和本地生成报告保持忽略，实际发布状态以 Git 提交与远程分支为准。价格输入为已采集的 AAPL 缓存；不将界面验收冒充完整基本面审核。

## 本轮落地

- 八位既有方法论人像保留源 RGB，使用本机 Apple Vision Accurate Person Segmentation 生成真 RGBA；面部保持不透明，只处理背景、裁断肩缘及身体底边。`assets/ajay-speakers/manifest.json` 记录来源、哈希、透明度和实测方法。
- 上海使用原始 4994×11270 实拍的高清衍生资产，桌面建筑长度为 2400–3600px（随视窗高度调整），手机 1350–1900px。保持原始纵向比例、裁掉两侧多余天空，不拉伸建筑；三个研究标记可直接跳至汇报或打开来源，展开证据不再撑大图片。
- 伦敦由小矩形照片改为估值章节全幅背景，横向与底部双渐变；深浅主题均维持文字对比。四个城市场景和人物仅保留小 `*`，说明统一置于页末，原实拍和重构来源分别署名。
- 删除虚拟缠论专家照片与旁白大列。大图集成日/周切换、平移缩放、十字 OHLC、均线/量柱/关键位/历史位/事件图层；图下讲解、七列结构表与画线共享 ID。
- 六步按原始 K 线、完成结构、未完成笔、中枢、候选点、失效条件解释本次快照。每步引用实际日期/价位；选择记录可直接聚焦。蜡烛与价格不做装饰性动画，仅当前结构线有定向画线。
- `chart_stock.py` 让 AI Agent 使用任意支持的股票代码或离线 OHLCV 输入，生成独立 HTML + JSON。正常 K 线采集也接入同一价格行为计算，详见 [`../CHART-WORKFLOW.md`](../CHART-WORKFLOW.md)。
