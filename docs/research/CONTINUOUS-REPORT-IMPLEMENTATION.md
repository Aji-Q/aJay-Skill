# aJay continuous report — implemented V3

2026-09-09. Replaces the single-screen city-switching Council as the default renderer. V2 remains a compatibility layout, not the accepted product direction.

## Architecture

`assemble_report` retains the existing analysis-quality boundary and rich financial renderers. `continuous_renderer` indexes only the already escaped output, moves each research block into its task chapter, and embeds local assets. `model_supplement` adds explicit structured views for ten previously omitted model products and the segment-model status. Raw provider strings remain escaped data; UI code uses DOM text nodes rather than HTML injection.

Six consecutive chapters: investment brief; business quality; valuation; market disagreement; decision conditions; research record. Nineteen dimension cards remain in the main document; eight portrait method perspectives link to evidence; the full 66-method note library keeps search, A–I filters, seat jumps and expand/collapse. Five model-directory anchors make the modelling desk directly addressable.

## Photograph-specific composition

- New York: a near-view Wall Street photograph beside a concrete security conclusion, supporting observation and counterevidence/gap. Not a generic photographic cover.
- Shanghai: one continuous portrait photograph spans the three-level business-quality narrative (about 2,464 px tall at the 1,280 px desktop viewport). Crown, body and foundation are revealed through normal document scrolling. On mobile, the portrait keeps its original proportion and three solid research annotations, each with an evidence action.
- London: the office facade's grid and diagonal lower structure frame a slate-paper model workspace. DCF assumptions and sensitivity are research content, not decorative numeric counters.
- Hong Kong: a full-ratio waterfront composition preserves the IFC crown/harbor relationship; explicit market-evidence and method-search links sit in the chapter opening.

No city tabs, repeating room template, automatic scene carousel, scroll hijacking or fake live market animation. Short chapter-heading reveals respect reduced-motion. Desktop sticky offset is applied once, not doubled.
