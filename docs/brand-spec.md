# aJay · Financial Research Council / V3 continuous

更新：2026-09-09；适用于个股主报告。当前主界面采用连续式金融研究汇报；root 已完成主要功能、视口、主题、reduced-motion、下载/分享、打印和视觉复核，屏幕阅读器仍待测，PE 历史图轴语义仍在修正。

## 身份与读者

- 身份：aJay / Aji-Q；当前分发仓库为 https://github.com/Aji-Q/aJay-Skill。
- 服务对象：需要快速判断、核对证据、理解估值假设和追踪反证的金融/投资研究读者。
- 页面不是实时行情终端，不把模拟人物写成真实名人荐股，也不把研究分数、覆盖度或模拟一致度写成上涨概率。
- 主页面以六个金融任务章节组织阅读；地点是章节的空间构图和节奏，不是可切换的城市背景。

## 核心叙事与空间

主线是“事实 → 生意 → 价格 → 分歧 → 条件 → 底册”，而非装饰驱动的场景秀。四张金融摄影衍生图各自服务一章或一段：

- **纽约 / Investment Brief**：Wall Street 街牌、石材斜线、前景虚化与人体尺度，作为抵达事实和执行摘要的入口。
- **上海 / Business Beneath the Price**：陆家嘴上海中心真实窄长竖幅；桌面上允许跨多个屏幕纵向阅读，建筑关系从楼身进入财务、公司与行业地基；始终保留竖向叙事，不缩成普通横幅。
- **伦敦 / Price Is an Assumption**：Greenland Dock 横向全景保留 One Canada Square 金字塔楼冠和 Canary Wharf 完整金融区识别，承担 DCF、Comps、LBO 与机构模型工作台，不冒充同一套“夜景背景”。
- **香港 / The Market Has Another View**：Central 与维港横向远近层次，承担多空冲突、市场路径和跨境视角。

第五章决策条件、第六章研究底册不额外增加换图标签。页面采用单一连续路径，不设置“城市 A/B/C/D”切换栏、不自动轮播，地点变化也不重置金融数据或人物状态。

## 版式与层次

- 桌面使用连续文档流与不对称空间：事实和研究文本占主导，照片承担方向、尺度和章节转场；拒绝通用卡片矩阵、完整矩形名人海报和“每城一个相同模块”。
- sticky 章节导航只指向六章；章节锚点为 `section-core`、`section-scan`、`section-modeling`、`section-clash`、`section-risks`、`section-library`，证据另有 `section-evidence`。
- 上海是唯一明确的纵向建筑长叙事；纽约近景、伦敦日间横向金融区、香港夜间维港保留各自原始比例和光学特征。
- 第一层给结论和边界，第二层给 19 维证据，第三层给机构模型，第四层给反方，第五层给条件，第六层给可追溯底册。折叠只是控制阅读密度，不隐藏输入。
- 研究记录与数值理解优先于摄影装饰；视差、光柱、漂浮粒子、霓虹边光和假数字动效均不作为信息层。

## 内容与功能契约

- **19 个基础维度**完整保留，按财务、行情、行业、公司、环境、安全六类进入连续页面；每个维度显示来源、时期/采集时间、状态和专属可视化或明确空状态。
- **机构模型**位于伦敦工作台：既有 DCF、Comps、Quick LBO、Initiating Coverage、IC Memo、Catalyst Calendar、Competitive Analysis 继续保留；独立 `model_supplement.py` 已接入，当前主页面显示 11 个补充块（10 个产品 + 1 个 segment 状态），覆盖三表、earnings、thesis、morning、screens、sector、unit economics、VCP、DD、rebalance 等原 UI 遗漏字段。
- **8 个方法人物**为巴菲特、格雷厄姆、芒格、林奇、索罗斯、达利欧、利弗莫尔、西蒙斯。它们是同一输入上的方法论视角，不是本人发言、独立投票或背书；人物数量和适用记录以当前输入为准。
- 人物观点旁的证据入口返回状态、来源、时期、采集时间、有限事实和原始维度记录。全量 panel/研究笔记保留组别筛选、关键词检索、强弱定位、反证条件与展开/收起。
- 决策章保留具体风险、失效条件、情景计划、条件价格区间和公开持仓观察；没有证据时显示缺口，不把默认倍数包装成 DCF 或支撑位。
- 研究底册保留下载输入、原生分享/打印 dialog、PDF 路径和摄影署名。分享不自动上传，不向远程二维码服务发送当前 URL。

## 视觉系统

### 色彩

连续式页面使用深海军蓝/黑曜石/银白的冷静层次：

- 深色底：`--bg-void #080e14`、`--bg-deep #0a1119`、`--bg-card #101b26`、`--bg-elevated #14202c`；
- 深色文字：`--text-bright #f0f1ee`、`--text-main #dbe1e3`、`--text-mid #acb9c2`、`--text-dim #9cabb7`；
- 强调：`--neon-gold #c5c3b0`（低饱和金属银灰）、`--neon-cyan #9bc3d8`（冷淡蓝灰）、`--bull-green #93c0b2`、`--bear-red #dfaaa4`；
- 浅色主题：`--bg-void #e5e9eb`、`--bg-deep #edf0f1`、`--bg-card #f6f7f7`、`--bg-elevated #fff`，强调色同步降饱和；
- 线条用于分组和阅读轨迹，不用荧光蓝边框、金色按钮或 HUD 发光模拟交易终端。

### 字体与文字

- 标题：`Iowan Old Style / Songti SC / STSong / Georgia`；
- 正文：`Avenir Next / PingFang SC / Microsoft YaHei`；
- 系统字体优先，无远程字体文件；
- 主判断约 18px / 1.65，反证约 15px / 1.65；移动端约 16px / 14px，先显示问题、判断和反证，再显示肖像；
- 语言保持克制、具体、可回到数据，不用 emoji 作为信息编码，不用“胜率”“必涨”等未经校准措辞。

## 动效与交互

- 本地 GSAP 只做章节标题的轻位移/透明度进入和受控阅读反馈；数字、图表和照片不从虚假零值动画到结果。
- 页面使用平滑滚动、sticky 导航和阅读进度；不抢滚轮、不自动切换地点、不自动轮播。
- 主题切换、`details` 折叠、证据 dialog、Esc/焦点恢复、评委席跳转、组别筛选、研究笔记关键词搜索、全部展开、下载和打印均为显式用户操作。
- `prefers-reduced-motion` 时关闭非必要过渡，保留正文、数据、证据和键盘路径。
- 主页面脚本用 DOM `textContent` 处理动态研究文本；原始数据不作为可执行 HTML 插入。
